// 01 — about

I work where real-time systems meet human perception — and what a system delivers is rarely what it thinks it is delivering.

My work runs as a loop. Design an apparatus — voice-coil actuators, stepper-driven linear stages, ESP32 firmware, an NI DAQ — drive it from Unity under deterministic sub-frame timing, then run controlled psychophysics against it: 2AFC sessions, PSE and JND estimates, detection thresholds, with 16 to 64 participants per study. The engineering and the measurement are the same job.

A physics BSc gives me the signal-processing and modelling side; an MSc in Human-Computer Interaction gives me experimental design, statistics and ethics protocols. I've deployed to Meta Quest 1/2/3, Apple Vision Pro, Valve Index and iPad, and shipped a consumer AR app to the App Store and Google Play.

// haptics · hardware + studies

Dual Linear-Stage Haptic Apparatus

Design, firmware, Unity integration & studies · VR Lab, Univ. of Birmingham

A robotic bimanual haptic rig that physically renders object widths from 3.5 to 90 cm: stepper-driven linear stages under ESP32-S3 firmware, integrated with Unity over a deterministic serial link so physical actuation and rendered visuals stay locked sub-frame. Built to answer a perceptual question — how far the virtual size of a grasped object can drift from the physical proxy before anyone notices — and used for the studies behind two manuscripts.

  • ESP32-S3
  • Stepper motors
  • Unity
  • C#
  • Serial
  • Psychophysics

// haptics · C++ / Syntacts

Haptic Feedback & Tactile Rendering Device

A real-time haptic rendering controller in C++ built on the Syntacts framework, synthesising, sequencing and streaming high-fidelity tactile signals to voice-coil actuators. Arduino firmware captures high-frequency analog sensor data over serial, and real-time signal mapping turns physical input into proportional actuator modulation. Custom enclosure designed and 3D-printed.

  • C++
  • Syntacts
  • Arduino
  • NI DAQ
  • Fusion 360

// research · Meta Quest

Hand Redirection Pipeline

A sensorimotor prediction pipeline injected into Meta Quest hand tracking. It continuously transforms the streamed pose time series to displace the rendered hand from the physical hand — staying below the detection threshold, so a single physical proxy can stand in for many virtual objects.

  • Unity
  • C#
  • Meta XR SDK
  • Hand tracking

// shipped · Swift / visionOS

AMUSER — Distributed Real-Time Sync

An adaptive tempo-sync engine (Swift with a C++ core) that keeps geographically distributed musicians synchronised in real time under variable transport delay, predicting and compensating for timing drift on a continuous stream. Shipped on iPad, with an immersive mixed-reality version on Apple Vision Pro running the same loop under head-tracked rendering constraints.
